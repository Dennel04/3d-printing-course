### Почему исправлен O-ring

В исходной учебной сборке показывалась канавка **Ø11,94 × ширина 2 мм** под предполагаемое кольцо **11×2,5 мм**. Для пробного эскиза принято: корень Ø11,50 и ширина 3,20. Если кольцо действительно 11×2,5, исходный внутренний Ø15,72, то приближённо:

- растяжение по внутреннему диаметру: `(11.50 − 11.0)/11.0 = 4,55%`;
- радиальная глубина канавки: `(15.72 − 11.50)/2 = 2,11 мм`;
- идеализированное радиальное сжатие: `(2.50 − 2.11)/2.50 = 15,6%` (до поправок на растяжение и допуски);
- идеализированное заполнение: `π × (2.50/2)² / (2.11 × 3.20) ≈ 72,7%` (до учёта растяжения, углов, материалов).

Это **оценка**, а не подтверждение герметичности. Давление нельзя подавать на этот купон. В штатной головке понадобятся расчёт допусков, материал уплотнения, ориентация, совместимость со смолой, регламентированное испытание.

## Как открыть и печатать

1. Открыть `3MF/LAB3_FIT_TESTS_ONE_PLATE.3mf` через **PrusaSlicer**.
2. Выбрать принтер **Prusa CORE One**, реальное сопло **HF0.4** (если оно установлено). Для пробной печати выбрать `0.20 mm SPEED` и **Prusament PLA**.
3. Для **единой раскладки из пяти объектов** нужен один материал — **чёрный PLA** из-за UV-кожуха. Для светлой платформы V3 из `Andmehõive` использовать отдельный файл Дениса.
4. Первичный ориентир: заполнение 15%; для C-зажима можно начать с 3–4 периметров, но проверить ориентацию слоёв и гибкость. Проверить в Preview каждый нависающий участок, мосты, заполнение, адгезию и автоматические поддержки — особенно зажим и внутренние выступы.
5. **Не печатать по данным из этого файла вслепую:** если PrusaSlicer показывает неподдерживаемые участки/серьёзные предупреждения, остановиться и исправить геометрию/ориентацию/опоры.
6. Экспортировать `.bgcode` только после реального Slice Now. Формат BGCODE рассчитан слайсером по профилю принтера; здесь BGCODE не создавался, а время/масса печати не вычислялись.
7. Проверить первый слой. По окончании — примерить и измерить детали; выявленные расхождения записать, затем изменить параметры в `source/build_models.py` и пересобрать.

### Важно для установки

**Ни один из этих пяти прототипов не следует сразу крепить как окончательный MG400-инструмент или включать в активную UV/пневмосистему.** Эти печати проверяют посадки и идею мест размещения. Лабораторные требования к единому инструменту, массе ≤500 г, 20 заменам шприца, 5-минутной проверке герметичности, 20 циклам, UV-безопасности и точным координатам остаются отдельными задачами.
