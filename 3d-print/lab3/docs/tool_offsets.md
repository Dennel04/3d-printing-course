# Tööriista nihked flantsi suhtes

Kõik nihked mõõdetakse valmis füüsiliselt tööriistalt ühe ja sama flantsi
referentsi suhtes. Ühik on millimeeter. CAD-i väärtust ei märgita mõõdetud
nihkeks.

Mõõdetakse neli nihet: napp, süstla tipp, UV-laik ja kaamera pildi keskpunkt.
Kaamera pildi keskpunkt tähendab valitud tööpinnal nähtavat keskpunkti, mitte
lihtsalt objektiivi mehaanilist keskpunkti. Märgi sihttasapind, töökaugus ja
J4/R asend; UV-laigu puhul ka valgustatud tasapind. Lab 2 vana napa
kalibreerimine R = 33° ei anna automaatselt uue tööriista nihkeid.
