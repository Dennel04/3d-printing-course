# study-ru — личные учебные заметки (не для оценивания)

Эта папка — **личный перевод и заметки на русском**, для собственного понимания.
Она **не является частью официальной сдачи курса** и не проверяется
преподавателем — рабочие материалы курса лежат в `3d-print/labN/README.md`
(на эстонском, как выдано).

Здесь:
- `lab1-translation.md` — полный перевод задания Lab 1 на русский.
- `lab2-translation.md` — полный перевод задания Lab 2 (оригинал: `3d-print/lab2/assignment-EST.md`).
- `lab3-translation.md` — полный перевод задания Lab 3 (оригинал: `3d-print/lab3/assignment-EST.md`).
- Дальше будут добавляться переводы следующих лаб и другие заметки.

Спорные термины в переводах даны с эстонским оригиналом в скобках. При
расхождении прав оригинал. Ссылки внутри переводов указывают на файлы
рядом с оригиналом (папка лабы), а не на `study-ru/`.
