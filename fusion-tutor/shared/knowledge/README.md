# Knowledge base

Verified material for the whole team. Each note starts with author and date.

- `fusion-mcp-tips.md`: Fusion MCP/API pitfalls and verified workarounds
  (freezes, active commands, cuts, f3z, hook v2).
- `lab2-webcam-mount.md`: mounting the Verbatim AWC-03 webcam above the table:
  decision, data, what to measure.
- `mg400-end-square.md`: the square at the end of the MG400 arm (XIAO camera
  mount): dimensions from CAD, where the robot model lives.
- Personal rules are in `../../people/<login>/my-rules.md`.
- Course assignments and measurements: `../../../3d-print/` (each lab's
  README and `docs/`).
- Russian translations of the assignments: `../../../study-ru/`.
- Official Fusion help: https://help.autodesk.com/view/fusion360/ENU/

Topic write-ups get one file per topic (`sketch-constraints.md`,
`parameters.md`, `fit-tolerances.md` ...): only what was verified in practice
or by official documentation.
