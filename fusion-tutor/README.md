# fusion-tutor — учитель по Fusion

Наставник по моделированию в Autodesk Fusion на Claude Code: смотрит твою модель
через Fusion MCP, подсказывает лесенкой (вопрос → инструмент → шаги), помнит
прошлые занятия. Учит, а не моделирует за тебя — но по просьбе может сделать сам,
с автоматическим чекпоинтом перед каждым изменением.

## Что нужно

- [Claude Code](https://claude.com/claude-code) и Python 3 в PATH (на нём хуки).
- Fusion: Preferences → General → API → включить **Fusion MCP Server**
  (порт 27182, путь `/mcp`).

## Как пользоваться

1. `cd 3d-printing-course/fusion-tutor && claude` — запускать **именно из этой
   папки**, иначе не подхватятся роль, команды и хуки. В первый раз: принять
   диалог доверия и одобрить MCP-сервер `fusion`.
2. `/lesson сегодня хочу ...` — начать занятие. В первый раз учитель создаст тебе
   `progress.md` и `my-rules.md` из `templates/` и начнёт с диагностики.
3. Моделируешь сам, спрашиваешь учителя, он смотрит модель.
4. `/rewind [N|last]` — откат документа к версии N (история не теряется) или
   отмена последнего шага.
5. `/lesson-end` — запись занятия в `log/`, обновление прогресса.

Документ в Fusion должен быть хоть раз сохранён в проект — иначе хук не даст его
менять (откатываться было бы некуда). Для опытов заведи себе документ-песочницу.

## Что важно знать

- **Полный доступ к Fusion без запросов.** Скрипты учителя — произвольный Python
  внутри Fusion. Защита: перед каждым изменением хук `tools/fusion_checkpoint.py`
  сохраняет версию документа («claude checkpoint …») и пишет всё в
  `log/fusion-actions.jsonl`; `ui.messageBox` запрещён (вешает Fusion).
- **Курс учитель читает без вопросов, а пишет только в эту папку.**
  `tools/guard_writes.py` отклоняет правки файлов вне `fusion-tutor/` и в свои хуки
  и настройки; shell-команды, которые меняют курс (`sed`, `cp` …), Claude Code
  спросит у тебя — не одобряй их. Git учитель не трогает — коммитишь ты.
  Это защита от ошибок, а не песочница: Python-скрипт в Fusion технически может
  записать что угодно на диск.

## Что личное, что общее

| Файл | В git? |
|---|---|
| `progress.md` — твоя карта навыков, ошибки, цели | нет, у каждого свой |
| `my-rules.md` — твои правила своими словами | нет |
| `log/` — журнал занятий и действий в Fusion | нет |
| `knowledge/` — проверенные данные и приёмы для всей команды | да |
| `CLAUDE.md`, `.claude/`, `tools/`, `templates/` — сам учитель | да |

Личные файлы не синхронизируются между устройствами — при желании держи их копию
где-нибудь у себя.
